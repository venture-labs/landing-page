    text: "Ein Multi-Agent-System besteht aus mehreren KI-Agenten, die jeweils eine eigene Aufgabe haben und zusammenarbeiten. Ein Agenten-Cluster ist ein solches System, das als Ganzes betrieben und überwacht wird."
  - type: "heading"
    text: "Wann was: ein Agent oder mehrere"
  - type: "paragraph"
    text: "Ein einzelner Agent mit gutem Playbook genügt, solange alle Aufgaben dieselben Rechte brauchen. Mehrere Agenten lohnen sich, wenn Aufgaben unterschiedliche Rechte, Werkzeuge oder Modelle verlangen oder wenn ein Fehler nach außen gehen könnte. Der Basis-Agent ist die gemeinsame Vorlage: Er legt fest, was jeder Agent mitbringt, und jeder weitere wird davon abgeleitet."  # prüfen: «Basis-Agent» als Begriff aus unserer Videoserie (Folge 3, nicht gedreht); Definition mit Christian abstimmen
  - type: "heading"
    text: "Ein Beispiel aus unserem eigenen Betrieb"
  - type: "paragraph"
    text: "In unserem eigenen Betrieb arbeitet ein Cluster aus mehreren Agenten für verschiedene Bereiche. Jeder hat eigene Ordner, eigene Werkzeuge und eigene Schlüssel, und gemeinsame Regeln gelten für alle. Ein Agent für Texte braucht keinen Zugriff auf Finanzdaten, ein Agent für Daten darf nichts veröffentlichen.
