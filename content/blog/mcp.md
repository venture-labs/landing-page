    text: "MCP steht für Model Context Protocol und ist ein offener Standard, mit dem KI-Anwendungen an externe Systeme wie Dateien, Datenbanken und Werkzeuge angebunden werden. Eingeführt hat ihn Anthropic im November 2024."  # prüfen: Definition und Herkunft nach modelcontextprotocol.io/docs/getting-started/intro (Abruf 09.11.2026: «open-source standard for connecting AI applications to external systems») und Anthropic-Ankündigung vom 25.11.2024 (anthropic.com/news/model-context-protocol, über Websuche bestätigt)
  - type: "heading"
    text: "Wie MCP funktioniert und wann es relevant ist"
  - type: "paragraph"
    text: "Die offizielle Dokumentation vergleicht MCP mit einem USB-C-Anschluss: Ein einheitlicher Stecker statt eines eigenen Kabels pro Gerät. Ein MCP-Server stellt Daten oder Werkzeuge bereit, eine KI-Anwendung als Client nutzt sie. Ohne Standard muss jede Anbindung einzeln gebaut werden, mit Standard können Anwendungen und Werkzeuge verschiedener Hersteller zusammenpassen."  # prüfen: USB-C-Vergleich und Client-Server-Aufbau gegen die offizielle Doku (modelcontextprotocol.io, Abruf 09.11.2026) abgleichen
  - type: "heading"
    text: "Abgrenzung zu Skill und Freigabe"
  - type: "paragraph"
    text: "Ein Skill liefert einem Agenten Wissen, MCP verschafft ihm Zugriff auf Systeme. Wer einem Agenten über MCP ein Werkzeug gibt, gibt ihm damit auch die Möglichkeit, etwas zu tun. Deshalb gelten dafür dieselben Regeln wie für jedes Recht: so wenig wie nötig, lesen vor schreiben, Freigabe vor Wirkung nach außen. Ein Standard macht die Anbindung einfacher, er macht sie nicht automatisch sicher."
  - type: "heading"
    text: "Beispiel aus der Praxis"
  - type: "paragraph"
    text: "Typisch ist ein Agent, der Werkzeuge nutzen kann: einen Kalender lesen, in Dokumenten suchen, einen Entwurf anlegen. Ob diese Werkzeuge über MCP oder auf anderem Weg angebunden sind, ist eine technische Entscheidung. Für den Nutzen im Unternehmen ist das zweitrangig. Wichtig ist, welche Rechte sie dem Agenten geben."  # prüfen: bewusst allgemein formuliert, kein Bericht aus dem eigenen Betrieb; ob und wo wir MCP selbst einsetzen, ist nicht belegt und müsste Christian bestätigen
