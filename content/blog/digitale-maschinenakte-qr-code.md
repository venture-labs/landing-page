    text: "Ein QR-Code an der Maschine löst ein einfaches Problem: Die Dokumentation liegt dort, wo man sie braucht, und nicht im Büro. Wer ihn scannt, landet auf einer Seite genau dieser Maschine. In fünf Schritten lässt sich das aufbauen: Zuerst wird entschieden, was hinter dem Code liegt, dann, wer es pflegt und wer Zugriff hat. Es folgt eine erste Maschine als Test, und zuletzt ein Logbuch, das Erfahrung festhält."
  - type: "heading"
    text: "Warum die Dokumentation an die Maschine gehört"
  - type: "paragraph"
    text: "Das Handbuch ist oft ein PDF irgendwo in einer Ablage. Was bei der letzten Reparatur gemacht wurde, weiß vielleicht eine einzige Person. Der Techniker vor der Maschine hat meist von beidem nichts zur Hand. Ein Etikett, das auf die Seite genau dieser Maschine führt, verkürzt die Suche. Es ersetzt keine Dokumentation, es macht vorhandene auffindbar."  # prüfen: Problemschilderung gemäß Landing Page digitale-maschinenakte; Wortlaut abgleichen
  - type: "heading"
    text: "Schritt 1: Festlegen, was hinter dem Code liegt"
  - type: "paragraph"
    text: "Am Anfang steht die Frage, was ein Techniker an der Maschine wirklich braucht. Typisch sind Handbuch, Schaltplan und Serviceberichte, dazu die Historie der Reparaturen und Services dieser einen Maschine. Mehr ist nicht besser: Eine Seite mit vierzig Dokumenten wird wieder zur Ablage. Sinnvoll ist, mit dem zu beginnen, wonach im Alltag tatsächlich gesucht wird."  # prüfen: Dokumente (Handbücher, Schaltpläne, Serviceberichte) und Historie entsprechen der Produktbeschreibung auf der Landing Page digitale-maschinenakte; Produktstand am Tag des Go-live gegen die Produktdokumentation abgleichen
  - type: "paragraph"
    text: "Hilfreich ist ein kurzer Blick auf die letzten Störungen: Welche Unterlage wurde damals gesucht, und wie lange hat es gedauert? Daraus ergibt sich die Reihenfolge der Inhalte."
  - type: "heading"
    text: "Schritt 2: Klären, wer pflegt"
  - type: "paragraph"
    text: "Eine Maschinenakte ist so gut wie das, was in ihr liegt. Deshalb braucht jede Maschine oder jede Gruppe von Maschinen eine benannte Person, die neue Dokumente einstellt und Veraltetes entfernt. Das muss nicht viel Zeit kosten, sollte aber festgelegt sein, bevor das erste Etikett hängt. Wird nach einer Reparatur der Bericht nicht abgelegt, ist die Seite nach einem halben Jahr unvollständig, und niemand verlässt sich mehr darauf."  # prüfen: Satz «so gut wie das, was in ihr liegt» entspricht der Landing Page digitale-maschinenakte
  - type: "heading"
    text: "Schritt 3: Zugriff regeln"
  - type: "paragraph"
    text: "Nicht jeder muss alles sehen. Der Techniker vor Ort braucht Handbuch und Historie, ein Kunde vielleicht nur bestimmte Unterlagen, das Büro die vollständige Akte. Wer was lesen und wer ergänzen darf, wird deshalb vor dem Start festgelegt, ebenso, welche Angaben nicht auf eine Seite gehören, die per Code erreichbar ist. Ein Etikett kann von jedem fotografiert werden, der an der Maschine steht."  # prüfen: Rollen- und Zugriffsmodell der Maschinenakte vor dem Go-live gegen die Produktdokumentation prüfen; die Landing Page sagt nur, Rollen und Datenschutz würden vor dem Start gemeinsam festgelegt. Keine konkrete Rechtezusage
  - type: "heading"
    text: "Schritt 4: Mit einer Maschine beginnen"
  - type: "paragraph"
    text: "Nicht alle Maschinen auf einmal. Gut geeignet ist eine Maschine, deren Wissen an wenigen Personen hängt oder die häufig Service braucht. Für sie werden Dokumente gesammelt, das Etikett angebracht und der Ablauf einige Wochen im Alltag erprobt. Danach zeigt sich, was fehlt, was überflüssig ist und ob der Code an der richtigen Stelle sitzt."
  - type: "paragraph"
    text: "Ein Etikett sollte dort sitzen, wo es auch im Betrieb erreichbar und lesbar bleibt, also nicht hinter einer Verkleidung, und geschützt gegen Öl, Staub und Reinigung. Als Etikett kommen QR-Code und NFC in Frage; ein NFC-Etikett wird angetippt, ein QR-Code gescannt."  # prüfen: QR- oder NFC-Etikett laut Landing Page digitale-maschinenakte; Hinweise zur Haltbarkeit sind allgemeine Praxis und nicht belegt, ggf. streichen oder mit dem Hersteller der Etiketten abklären
  - type: "heading"
    text: "Schritt 5: Ein Logbuch ergänzen"
  - type: "paragraph"
    text: "Dokumente beantworten, wie eine Maschine gebaut ist. Das Logbuch hält fest, wie sie sich im Betrieb verhält: eine Störung, eine Wartung, eine Beobachtung. Am besten geht das kurz und ohne Formularaufwand, als ein Satz, ein Foto oder ein Diktat direkt an der Maschine. Der Wert entsteht, weil der Eintrag an dieser einen Maschine hängt und nicht in einem allgemeinen Dokument."  # prüfen: Logbuch (optional) per Text, Foto oder Diktat laut Landing Page digitale-maschinenakte; Produktstand gegen die Produktdokumentation prüfen
  - type: "paragraph"
    text: "Ein Logbuch dient dem Wissen über die Maschine und nicht der Kontrolle der Mitarbeitenden. Das sollte vor dem Start klar gesagt werden, sonst bleiben die Einträge aus."  # prüfen: Aussage «keine Leistungskontrolle» entspricht der Landing Page digitale-maschinenakte
  - type: "heading"
    text: "Was ein QR-Code nicht leistet"
  - type: "paragraph"
    text: "Der Code ist nur der Zugang. Ohne gepflegte Inhalte führt er auf eine leere oder veraltete Seite. Er ersetzt weder Schulung noch Sicherheitsunterweisung, und er ändert nichts daran, dass Wissen, das nie aufgeschrieben wurde, auch nicht nachgeschlagen werden kann."
  - type: "heading"
    text: "Der nächste Schritt"
  - type: "paragraph"
    text: "Für die erste Maschine genügt ein Gespräch über vorhandene Maschinen und Dokumente. Gemeinsam lässt sich klären, womit ein Start sinnvoll ist. Zu Aufwand und Dauer gibt es hier keine pauschale Zahl, sie hängen von der Zahl der Maschinen und der vorhandenen Unterlagen ab."  # prüfen: bewusst keine Aussage zu Dauer und Aufwand, wie auf der Landing Page digitale-maschinenakte
