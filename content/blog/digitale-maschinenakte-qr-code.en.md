  - type: "paragraph"
    text: "A QR code on the machine solves a simple problem: the documentation is where it is needed, not in the office. Whoever scans it lands on a page for exactly this machine. It can be built in five steps: first decide what sits behind the code, then who maintains it and who has access. A first machine follows as a test, and finally a logbook that records experience."
  - type: "heading"
    text: "Why documentation belongs on the machine"
  - type: "paragraph"
    text: "The manual is often a PDF somewhere in a folder. What was done in the last repair may be known to a single person. The technician in front of the machine usually has neither at hand. A label that leads to the page of exactly this machine shortens the search. It does not replace documentation, it makes existing documentation findable."  # prüfen: problem description per landing page digitale-maschinenakte; compare wording
  - type: "heading"
    text: "Step 1: Decide what sits behind the code"
  - type: "paragraph"
    text: "It starts with the question of what a technician at the machine really needs. Typical are the manual, circuit diagram and service reports, plus the history of repairs and services of this one machine. More is not better: a page with forty documents becomes a filing cabinet again. It makes sense to begin with what is actually searched for in daily work."  # prüfen: documents (manuals, circuit diagrams, service reports) and history match the product description on the landing page digitale-maschinenakte; compare product status against the product documentation on the go-live day
  - type: "paragraph"
    text: "A short look at the latest faults helps: which document was searched for then, and how long did it take? That gives the order of the content."
  - type: "heading"
    text: "Step 2: Clarify who maintains it"
  - type: "paragraph"
    text: "A machine file is only as good as what is in it. So each machine or group of machines needs a named person who adds new documents and removes outdated ones. This need not take much time, but should be settled before the first label hangs. If the report is not filed after a repair, the page is incomplete after half a year and nobody relies on it any more."  # prüfen: sentence "only as good as what is in it" matches the landing page digitale-maschinenakte
  - type: "heading"
    text: "Step 3: Regulate access"
  - type: "paragraph"
    text: "Not everyone needs to see everything. The technician on site needs manual and history, a customer perhaps only certain documents, the office the complete file. Who may read and who may add is therefore decided before the start, as is which information does not belong on a page reachable by code. A label can be photographed by anyone standing at the machine."  # prüfen: roles and access model of the machine file to be checked against the product documentation before go-live; the landing page only says roles and data protection are agreed together before the start. No concrete rights promise
  - type: "heading"
    text: "Step 4: Start with one machine"
  - type: "paragraph"
    text: "Not all machines at once. A machine whose knowledge depends on few people or which often needs service is well suited. Documents are collected for it, the label is attached and the process is tried in daily work for a few weeks. Then it shows what is missing, what is superfluous and whether the code sits in the right place."
  - type: "paragraph"
    text: "A label should sit where it stays reachable and readable in operation, so not behind a cover, and be protected against oil, dust and cleaning. QR code and NFC come into question as labels; an NFC label is tapped, a QR code is scanned."  # prüfen: QR or NFC label per landing page digitale-maschinenakte; durability hints are general practice and not sourced, delete or clarify with the label manufacturer
  - type: "heading"
    text: "Step 5: Add a logbook"
  - type: "paragraph"
    text: "Documents answer how a machine is built. The logbook records how it behaves in operation: a fault, a maintenance job, an observation. This works best short and without form effort, as a sentence, a photo or a dictation right at the machine. The value arises because the entry is attached to this one machine and not to a general document."  # prüfen: logbook (optional) by text, photo or dictation per landing page digitale-maschinenakte; check product status against the product documentation
  - type: "paragraph"

    text: "What a QR code does not do"
  - type: "paragraph"
