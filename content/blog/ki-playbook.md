  - type: "heading"
    text: "Wann ein Playbook reicht und wann nicht"
  - type: "paragraph"
    text: "Ein Playbook beschreibt den Ablauf, eine Rolle legt fest, aus welcher Perspektive der Agent arbeitet, ein Skill ist ein Wissenspaket, das bei Bedarf dazukommt. Ein Playbook reicht, solange dem Agenten nur Wissen oder ein Ablauf fehlt. Es ist eine Bitte und keine Sperre: Was ein Agent nicht darf, regeln Rechte und Freigaben."
  - type: "heading"
    text: "Beispiel aus dem eigenen Betrieb"
  - type: "paragraph"
    text: "In unserem eigenen Betrieb haben Agenten für wiederkehrende Aufgaben je ein Playbook auf etwa einer Seite: was das Ziel ist, welche Schritte folgen, was nie passieren darf und wie das Ergebnis aussehen soll. Ändert sich ein Ablauf, wird der Text angepasst, ohne dass am Agenten selbst etwas gebaut wird. Stand: 09.11.2026."  # prüfen: Geschichte aus dem eigenen Betrieb (Playbooks als einseitige Texte je Aufgabe) braucht Christians Freigabe; Formulierung gegen die tatsächliche Praxis abgleichen
  - type: "heading"
    text: "Wo ein Playbook im Unternehmen hilft"
  - type: "paragraph"
    text: "Sinnvoll ist ein Playbook für Aufgaben, die oft vorkommen, einen klaren Ablauf haben und deren Ergebnis sich schnell prüfen lässt: Mails sortieren, Anfragen vorqualifizieren, Berichte in festem Format vorbereiten. Am Anfang steht eine Aufgabe, die jemand im Team bereits gut kennt. Das Wissen dieser Person wird aufgeschrieben und an echten Fällen geprüft."
