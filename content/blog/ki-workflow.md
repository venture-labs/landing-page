    text: "Wann was: Workflow oder Agent"
  - type: "paragraph"
    text: "Beim Workflow steht der Weg fest, beim Agenten entscheidet das Modell über den Weg. Ein Workflow ist vorhersagbar und gut prüfbar, ein Agent ist flexibler, aber schwerer zu überblicken. Sinnvoll ist, mit dem Workflow zu beginnen und einen Agenten erst zu nehmen, wenn sich der Weg nicht vorab beschreiben lässt."  # prüfen: Empfehlung gestützt auf Anthropic, «Building effective agents», abgerufen 09.11.2026 (Workflows für klar umrissene Aufgaben, Agenten bei Bedarf an Flexibilität)
  - type: "heading"

  - type: "paragraph"
    text: "Eingehende Anfragen werden immer gleich bearbeitet: einlesen, Art erkennen, Entwurf schreiben, an eine Person zur Freigabe geben. Das ist ein Workflow. Soll dagegen eine offene Frage aus mehreren Quellen geklärt werden, wobei vorher unklar ist, welche Quelle gebraucht wird, passt ein Agent besser."
