    text: "KI-Agenten dürfen Mails selbst senden, wenn Kontrolle und Freigabe vorher geregelt sind, und für die meisten Mails ist es sinnvoll, damit nicht zu beginnen. Bewährt hat sich ein Vorgehen in Stufen: Der Agent schreibt zunächst nur Entwürfe, ein Mensch liest und sendet. Erst wenn sich eine enge Art von Mail über viele Fälle bewährt hat, kommt ein automatischer Versand in Frage, und für Geld, Verträge und Beschwerden bleibt er dauerhaft ausgeschlossen."
  - type: "heading"
    text: "Entwurf statt Versand: die Grundregel"
  - type: "paragraph"
    text: "Ein Agent kann viel lesen, ohne Schaden anzurichten. Kritisch wird es beim Schreiben nach außen, weil eine versendete Mail nicht zurückgeholt werden kann. Deshalb gilt als Grundregel: Lesen ja, Wirkung nach außen nur mit Freigabe. Wo ein Agent etwas verschicken würde, entsteht ein Entwurf, und ein Mensch gibt ihn frei."  # prüfen: deckt sich mit dem geprüften Landing-Page-Text ki-agenten-unternehmen («Lesen darf ein Agent viel, schreiben nur mit Freigabe»); gegen den laufenden Cluster abgleichen
  - type: "paragraph"
    text: "Die Freigabe ist dabei keine Geste, sondern die Stelle, an der ein Mensch Ton, Inhalt und Zusagen prüft. Ein Entwurf ist ein Vorschlag, kein fertiges Ergebnis, und das gilt auch bei gut laufenden Agenten."
  - type: "heading"
    text: "Zwei Agenten statt einem: Lesen und Schreiben trennen"
  - type: "paragraph"
    text: "Eine wirksame Absicherung ist, die Aufgaben auf zwei Agenten zu verteilen. Der eine sortiert das Postfach und erkennt, welche Mail eine Antwort braucht und zu welchem Vorgang sie gehört. Der andere schreibt nur den Entwurf für genau diese eine Mail. Wer liest, braucht kein Schreibrecht. Wer schreibt, braucht keinen Zugriff auf das ganze Postfach, sondern nur auf das, was für diese Antwort nötig ist."  # prüfen: Konzept «zweiter Agent schreibt nur Entwürfe» laut Idee «Mail-Antworten: ein zweiter Agent schreibt nur Entwürfe» (04.11., #2, content-ki-cluster/ideen.md); Christian bestätigt, dass die Beschreibung so seinem Konzept entspricht

  - type: "heading"
    text: "Drei Stufen der Autonomie"
  - type: "paragraph"
    text: "Stufe 1 ist der Entwurf: Der Agent schreibt, der Mensch liest, ändert und sendet. Jede Änderung und jede unveränderte Freigabe zeigt, wie zuverlässig der Agent für diese Mailart arbeitet."
  - type: "paragraph"
    text: "Stufe 2 ist der automatische Versand für genau eine enge Mailart, etwa die Antwort auf Anfragen, die immer gleich ablaufen. Die Schwelle ist eine Zahl und kein Gefühl: In unserem eigenen Fall darf der Agent erst automatisch antworten, nachdem zehn seiner Entwürfe von Hand gesendet wurden. Zehn ist dabei die Schwelle für diesen einen Fall und kein Standard für alle."  # prüfen: Idee «Wann darf der Agent allein senden? Nach zehn manuellen Sendungen» (04.11., #3).   - type: "paragraph"
    text: "Stufe 3 ist der Rückfall. Wenn Entwürfe häufig geändert werden müssen, bleibt der Agent in Stufe 1 oder fällt dorthin zurück. Autonomie ist kein Dauerzustand, sie wird laufend verdient."  # prüfen: Rückfallregel laut Idee #3 («Wenn ich oft ändere, bleibt er in Stufe 1»); ob sie technisch eingebaut ist, vor dem Go-live prüfen
  - type: "heading"
    text: "Was nie automatisch versendet werden sollte"
  - type: "paragraph"
    text: "Bei Geld, Verträgen, Beschwerden und rechtlichen Fragen schreibt ein Mensch selbst oder prüft jeden Satz. Das gilt auch dann, wenn der Agent in Stufe 2 für andere Mails längst zuverlässig arbeitet. Der Grund ist einfach: Der mögliche Schaden einer falschen Mail ist dort größer als der Zeitgewinn."
